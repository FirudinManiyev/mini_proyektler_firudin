# 50 Mini Layihə

HTML, CSS və Vanilla JavaScript istifadə edərək hazırlanmış mini web layihələrin toplusu.

## 📋 Haqqında

Bu layihə mənim web inkişaf etdirmə bacarıqlarımı artırmaq üçün hazırladığım 50 mini layihənin kolleksiyasıdır. Hər layihə müstəqildir və framework-lərdən asılı deyil.

## 🚀 Mövcud Layihələr

- **Music Player** - Qramafon dizaynlı musiqi pleyeri
- **Cup Game** - Coin olan stəkanı tapmaq oyunu

## 🎯 Məqsəd

50 müxtəlif mini layihə hazırlamaq və web inkişaf etdirmə bacarıqlarını təkmilləşdirmək.

## 🛠️ Texnologiyalar

- HTML5
- CSS3
- Vanilla JavaScript

## 📁 Struktur

```
/
├── index.html          # Ana səhifə
├── style.css           # Ümumi stillər
├── assets/             # Resurslar
└── projects/           # Mini layihələr
    ├── 01. Music Player/
    └── 02. Cup Game/
```
